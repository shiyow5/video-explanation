# 図とアイコン

## どの場面で見せるか

内容に合わせて場面の種類を選ぶ。文字だけの箇条（bullets）は、ほかの種類で表せないときに使う。

| 見せたいこと | kind | 動き |
|---|---|---|
| 処理の流れ、分岐と合流、仕組みの構成 | diagram | 箱が列の順に出て、線が引かれ、線の上を点が流れ続ける |
| 一本道の手順（4段まで） | flow | 箱が順に出て、箱のあいだを点が動く |
| 割合（何割、何％） | ratio | 円が満ちながら中央の数字が数え上がる |
| 改善の前と後 | compare | 後の棒が前の長さから縮む（伸びる）。差の札と、スタンプ（「半分以下」など） |
| 期間・計画と実績 | timeline | 帯が始まりから終わりへ伸びる。予定は斜線。「この時点」の赤い線 |
| 関わる人・道具・概念の紹介 | icons | 大きなアイコンが線を描くように現れる |
| 大きな数字 | stats | 数え上げ |
| 複数の値の比較 | bars | 棒が伸びる |
| 判断 | decision | 候補が並び、理由の文で採用の印 |
| 成果物の年表 | docs | 線が伸び、項目が順に滑り込む |

項目に`icon`を付けると、bullets・stats・flow・decision・compare・diagram・timeline・iconsの各場面にアイコンが出る。

## フロー図を作る（diagram）

箱を列（`g`、0〜3）に分けて置き、`to`でつなぎ先の項目の番号を書く。`to`を1つも書かないときは、前の列のすべての箱から次の列の箱へ自動でつなぐ。

```json
{
  "kind": "diagram",
  "items": [
    { "t": "受付", "s": "問い合わせを読む", "icon": "mail", "g": 0, "to": [1], "l": 0 },
    { "t": "分類", "icon": "tags", "g": 1, "to": [2, 3], "l": 0 },
    { "t": "下書き", "icon": "file-pen-line", "g": 2, "to": [4], "l": 1 },
    { "t": "人が書く", "icon": "pen-line", "g": 2, "to": [4], "l": 1 },
    { "t": "送信", "icon": "send", "g": 3, "l": 2 }
  ]
}
```

- 右の列へは横の曲線、同じ列の中は縦の線、左の列へ戻る線は下を回る曲線で描く。
- 1列の箱は4個まで。超えるときは図を2つの場面に分ける。
- 箱の文字は、箱の幅に1行で収まる大きさに自動で縮む。短い言葉にするほど読みやすい。
- 線は、つなぎ先の箱が出る直前に引かれる。説明の文の順（`l`）と、列の順をそろえる。

## アイコンを探す

アイコンはLucide（ISCライセンス、線だけで描いた約1,900種）を使う。名前はhttps://lucide.dev/icons/ と同じ表記（例`file-text`）で書く。

```bash
python3 scripts/find_icon.py データ 検索                  # 候補の名前を表示（日本語のよく使う語は英語に置き換えて探す）
python3 scripts/find_icon.py chart --sheet out/icons.png  # 候補を並べた画像を作って見比べる
```

`find_icon.py`は手元に入っているlucide-reactの名前だけを調べ、ネットには問い合わせない。顔や生き物に見えるアイコン（bot、smile、catなど）は候補から外す。台本の点検（`check_script.py`）でも、実在しない名前と、顔や生き物に見えるアイコンはエラーになる。

選ぶときの目安は次のとおり。

- 1つの場面の中で、アイコンの太さと大きさをそろえる（ひな形は自動でそろう）。
- 意味が一目で分かるものを選ぶ。迷う場合は文字だけにする。
- 同じ概念には、動画全体で同じアイコンを使う。

## アイコンを作る

Lucideに合うものが無いときは、`src/custom-icons.tsx`にSVGの線で描いて足し、台本では`"icon": "custom:<名前>"`と書く。

- 24 x 24の範囲に、線（`path`・`circle`・`rect`）だけで描く。塗り（fill）は使わない。
- 線の太さ・色・角の丸めは書かない（親から受け継ぐので、Lucideと同じ見た目になる）。
- 端から1〜2の余白を空ける。線は長くても1本90以内（線を描く動きの長さ）にする。
- 描いたら`python3 scripts/find_icon.py <名前> --sheet out/icons.png`で、Lucideと並べて見比べる。
- 顔・キャラクター・実在の会社のロゴは描かない。

```tsx
// 例: 資料（棒グラフ入りの報告書）
const Report: CustomIcon = () => (
  <>
    <path d="M6 2h9l4 4v16H6z" />
    <path d="M15 2v4h4" />
    <path d="M9 18v-3" />
    <path d="M12.5 18v-6" />
    <path d="M16 18v-4" />
  </>
);
```

## アイコンを動かす

項目の`motion`で選ぶ。書かなければ`draw`になる。

| motion | 動き | 向いているもの |
|---|---|---|
| draw | 線を描くように現れる | 既定。図や道具の紹介 |
| pop | ばねで拡大しながら出る | 結果、印 |
| pulse | 出たあと、ゆっくり脈打つ | 今注目してほしいもの（1場面に1つまで） |
| spin | 出たあと、ゆっくり回る | 処理中、設定、更新 |
| bounce | 出たあと、小さく弾む | 改善、うまくいったこと（1場面に1つまで） |
| none | 動かさない | 一覧の画像など |

動き続けるもの（pulse・spin・bounce）を1つの画面に並べすぎると、見る人の目が字幕から離れる。1場面に1つまでにする。
