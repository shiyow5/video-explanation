# 専門用語と固有名詞

経緯の動画でも論文の解説でも、次の決まりで書く。依頼者から実際に受けた指示に基づく。

## 決まり

1. 専門用語は、ふだんの言葉に言い換えずにそのまま使う。初めて出たところで解説を入れる。
2. 固有名詞（手法・モデル・データセット・指標・製品などの名前）は、そもそも置き換えない。
3. 専門外の人にも分かるように、固有名詞は解説のあとも、出てくるすべての文で何の名前かを添える。例「検索手法のQuickRank」「QuickRankという検索手法」「評価データのSampleQA」。
4. 例外は、依頼者が伏せると決めた社名・店名だけ（A社・B社に置き換える）。

言い換えると、元の論文や資料と照らし合わせられなくなる。名前を残したうえで、何の名前かを添えれば、詳しくない人にも分かる文になる。

## 台本への書き方

```json
{
  "glossary": {
    "コサイン類似度": "2つのベクトルの向きの近さ。1に近いほど似ている"
  },
  "names": {
    "QuickRank": { "what": "検索手法", "desc": "この論文が提案する、2段階で探す検索手法" }
  },
  "readings": [["QuickRank", "クイックランク"]],
  "scenes": [
    {
      "terms": ["QuickRank"],
      "lines": [{ "text": "この論文は、検索手法のQuickRankを提案しています。" }]
    }
  ]
}
```

| 欄 | 書くこと |
|---|---|
| glossary | 専門用語 → 説明（40字まで） |
| names | 固有名詞 → `what`（何の名前か。文に添える言葉）と`desc`（説明。40字まで） |
| readings | その動画だけの読み（固有名詞の読みなど）。`scripts/readings.json`に足される |
| terms（場面） | その場面で初めて出る用語・固有名詞。字幕の上に説明の札が出る。1場面2つまで |

読み上げでも、初出では一言説明する（例「コサイン類似度、つまり2つのベクトルの向きの近さです」）。札だけに頼らない。

## 点検でわかること

`check_script.py`は次の場合にエラーにする。

- glossaryかnamesにある言葉が、`terms`の無い場面で初めて出ている（説明なしで使っている）
- namesの固有名詞が出てくる文（字幕と、画面の項目の文）に、その`what`の言葉が入っていない
- `terms`に書いた言葉がglossaryにもnamesにも無い

見出し（title・label）は短いので、3つ目の決まりの対象にしない。表のセルも、列の見出しで何の名前かが分かるようにする（例: 列「検索手法」の下に「QuickRank」）。

## 文体を整えるとき

読みやすく直すとき（yomiyasuなど）も、専門用語と固有名詞は言い換えない。分かりにくければ、言い換えではなく説明や「何の名前か」を足して直す。
