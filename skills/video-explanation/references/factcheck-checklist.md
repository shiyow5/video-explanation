# ファクトチェックの項目

台本（全場面の字幕・画面の文字）と文書を対象に、主張を1件ずつ表にして確かめる。サブエージェントに頼むときは、一次資料の場所とこの一覧を渡し、判定（一致・誤り・要注意）と根拠の資料名を返させる。

## 事実

| 項目 | 確かめること |
|---|---|
| 数値 | 原資料の値と一致するか。評価データの件数・条件（何枚・何件で測ったか）まで合っているか |
| 日付 | 資料の日付と一致するか。受け取った日と作った日を取り違えていないか |
| 主体 | 作成者・決めた主体・担当者が資料と一致するか |
| 判断 | 候補・選ばれたもの・理由が資料のとおりか。理由が別の時期の資料から来ていないか |
| 範囲 | 一部の費用・一部の対象の値を、全体の値のように書いていないか |
| 断定 | 資料に無い言い切り（「予告なく」「初めて」など）を足していないか |
| 食い違い | 資料間で値が違うものを、片方だけ断定していないか |

## 依頼者の指示

| 項目 | 確かめること |
|---|---|
| 未来の情報 | 各場面に、その時点より後の結果・評価・名前が出ていないか（`check_script.py`の日付の点検に加えて、日付の無い言い回しも読む） |
| 担当の明記 | 個人の作業に担当者名と出典があるか。特定の人の担当分しか扱わない段階で、そう言っているか |
| 口調と絵 | キャラクターの口調、アイコン、キャラクターに見える絵が無いか |
| 伏せる名前 | 社名・店名などが字幕・画面・文書に無いか（`--banned`の点検に加えて、表記ゆれも読む） |
| 外部送信 | 資料や台本を外部のサービスに送っていないか |
| クレジット | 「VOICEVOX:ずんだもん」が動画の中にあるか |

## 直し方

誤りは本文を直し、表に「直す前 → 直した後」を残す。確かめられない主張は、数値や断定を外して弱めるか、場面ごと削る。直したら台本の点検・音声・書き出しをやり直す。
